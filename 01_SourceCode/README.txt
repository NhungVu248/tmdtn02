01_SourceCode — MÃ NGUỒN DỰ ÁN STAYTOUR

Mã nguồn đầy đủ nằm ở thư mục gốc của dự án:
  - backend/   : máy chủ Node.js/Express + Prisma + API
  - frontend/  : giao diện React + Vite + Tailwind

KHI ĐÓNG GÓI NỘP: chép 2 thư mục backend/ và frontend/ vào đây, và LOẠI BỎ:
  - node_modules/   (thư viện đã cài — cài lại bằng npm install)
  - frontend/dist/  (bản build — tạo lại bằng npm run build)
  - *.env           (tệp cấu hình chứa bí mật — dùng .env.example làm mẫu)

Hướng dẫn chạy: xem README.txt ở thư mục gốc và 03_Deployment/.
